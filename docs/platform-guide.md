## 平台概述

智能体平台是一个类似 Dify/Coze 的 AI Agent 开发平台，支持以下三种应用类型：

- **聊天助手**：基础对话应用，支持知识库和工具调用
- **Agent 编排**：使用 LangChain ReAct Agent 实现智能体，支持自主决策和工具调用
- **工作流**：可视化 DAG 工作流编排，支持复杂业务流程

### 核心功能
- 🤖 多模型支持（OpenAI、Anthropic 等）
- 📚 知识库 RAG（检索增强生成）
- 🔧 工具调用（内置工具 + MCP 协议）
- 💬 多轮对话（支持记忆窗口）
- 📊 工作流编排（7 种节点类型）

## 快速开始

### 1. 注册与登录
1. 访问平台首页
2. 点击「注册」按钮
3. 填写用户名、邮箱和密码
4. 登录后进入仪表盘

1. 进入「模型管理」页面
2. 点击「添加模型供应商」

1. 进入「应用管理」页面
2. 点击「创建应用」
3. 选择应用类型（聊天助手/Agent/工作流）
4. 填写应用名称和描述
5. 开始配置应用

## 聊天助手

聊天助手是最基础的应用类型，适合简单的问答场景。

### 配置项

#### 1. 提示词（Prompt）
```
你是一个专业的客服助手，请根据知识库内容回答用户问题。
如果知识库中没有相关信息，请礼貌地告知用户。
```

**提示词变量**：
- 使用 `{{variable_name}}` 语法定义变量
- 在「变量」卡片中管理变量
- 支持文本、段落、文件上传等类型

#### 2. 模型配置
- **模型选择**：选择已配置的模型
- **温度（Temperature）**：0-1，越高越随机
- **最大 Token**：回复的最大长度
- **Top P**：核采样参数

#### 3. 知识库
1. 在「知识库」卡片点击「+ 添加」
2. 选择已创建的知识库
3. 配置检索参数：
   - **检索模式**：语义检索 / 全文检索 / 混合检索
   - **返回数量**：返回相关片段数量（默认 3）
   - **相似度阈值**：低于此分数的片段不返回

#### 4. 变量管理
点击「+ 添加变量」创建自定义变量：
- **变量名**：英文标识符
- **显示名称**：界面显示的名称
- **类型**：文本 / 段落 / 文件
- **默认值**：可选的默认值
- **必填**：是否为必填项

## Agent 编排

Agent 编排使用 LangChain ReAct Agent 实现，支持自主决策和工具调用。

### 与聊天助手的区别
| 特性 | 聊天助手 | Agent 编排 |
|------|----------|------------|
| 执行方式 | 直接生成回复 | 思考 → 行动 → 观察循环 |
| 工具调用 | 需要预定义调用链 | 自主决定何时使用工具 |
| 适用场景 | 简单问答 | 复杂任务、多步骤推理 |

### 配置项

#### 1. 提示词
Agent 的系统提示词决定了 Agent 的行为模式。示例：
```
你是一个智能助手，可以帮助用户完成各种任务。

你可以使用以下工具：
- 搜索工具：搜索相关信息
- 计算器：进行数学计算
- 代码执行器：运行 Python 代码

请根据用户需求，自主决定使用哪些工具来完成任务。
```

#### 2. 工具配置
1. 在「工具」卡片点击「+ 添加」
2. 选择已安装的工具
3. 可选：自定义工具参数

**可用工具类型**：
- **搜索类**：Tavily Search、DuckDuckGo Search
- **网页类**：Web Scraper、HTML to Markdown
- **文件类**：PDF Reader、CSV Parser
- **代码类**：Code Executor
- **数据库类**：SQL Query

#### 3. 高级参数
- **最大迭代次数**：Agent 思考-行动循环的最大次数（默认 10）
- **记忆窗口**：保留的历史消息数量（默认 50）

### 执行流程
```
用户提问
    ↓
Agent 思考（分析问题，决定是否需要工具）
    ↓
┌─ 需要工具 → 调用工具 → 获取结果 → 继续思考
│
└─ 不需要 → 直接生成回复
    ↓
返回最终答案
```

## 工作流

工作流使用可视化 DAG 编排，适合复杂的业务流程。

### 节点类型
| 节点 | 说明 |
|------|------|
| 开始 | 工作流入口，定义输入参数 |
| LLM | 调用大语言模型 |
| 知识库检索 | 从知识库获取相关片段 |
| 工具调用 | 调用外部工具 |
| 代码执行 | 运行自定义代码 |
| 条件分支 | 根据条件选择不同路径 |
| 结束 | 工作流出口，定义输出 |

### 创建工作流
1. 进入应用的「工作流」标签
2. 从左侧拖拽节点到画布
3. 连接节点之间的连线
4. 配置每个节点的参数
5. 点击「运行」测试工作流

### 示例：问答工作流
```
[开始] → [知识库检索] → [LLM 生成回复] → [结束]
```

## 知识库管理

知识库用于存储和检索文档，支持 RAG（检索增强生成）。

### 创建知识库
1. 进入「知识库管理」页面
2. 点击「创建知识库」
3. 填写名称和描述
4. 选择嵌入模型（用于向量化）

### 上传文档
支持的文件格式：
- 📄 文本：TXT、Markdown
- 📑 文档：PDF、Word、TXT
- 📊 表格：CSV、Excel
- 🌐 网页：URL 抓取

### 文档处理流程
```
上传文档
    ↓
文本提取（解析文件内容）
    ↓
文本分片（按语义或固定长度分割）
    ↓
向量化（使用嵌入模型）
    ↓
存储到向量数据库
```

### 分片策略
- **自动分片**：系统自动按语义分割
- **自定义分片**：指定分隔符或固定长度
- **分片大小**：建议 500-1000 字符
- **重叠**：相邻片段重叠 50-100 字符

### 检索配置
- **语义检索**：基于向量相似度（推荐）
- **全文检索**：基于关键词匹配
- **混合检索**：结合语义和全文

## 模型配置

### 支持的模型供应商
| 供应商 | 模型示例 |
|--------|----------|
| OpenAI | GPT-4、GPT-3.5-turbo |
| Anthropic | Claude 3 Opus、Claude 3 Sonnet |
| 本地模型 | 通过 Ollama 等接入 |

### 添加模型供应商
1. 进入「模型管理」页面
2. 点击「添加供应商」
3. 选择供应商类型
4. 填写配置：
   - **名称**：供应商显示名称
   - **API Key**：密钥
   - **基础 URL**：API 地址（可选）
5. 点击「测试连接」验证
6. 保存配置

### 模型参数说明
| 参数 | 范围 | 说明 |
|------|------|------|
| Temperature | 0-2 | 创造性，越高越随机 |
| Top P | 0-1 | 核采样，控制多样性 |
| Max Tokens | 1-4096 | 最大输出长度 |
| Frequency Penalty | 0-2 | 降低重复词概率 |

## 常见问题

### Q1: 如何选择应用类型？
- **简单问答** → 聊天助手
- **需要工具调用、自主决策** → Agent 编排
- **复杂业务流程、多步骤** → 工作流

### Q2: 知识库检索效果不好？
1. 检查文档分片是否合理
2. 调整检索参数（返回数量、相似度阈值）
3. 尝试不同的检索模式
4. 优化嵌入模型选择

### Q3: Agent 不调用工具？
1. 确保已添加工具到 Agent
2. 检查系统提示词是否明确说明工具用途
3. 增大「最大迭代次数」参数
4. 查看 Agent 日志了解决策过程

### Q4: 如何提高回复质量？
1. 优化系统提示词（明确角色、任务、约束）
2. 选择合适的模型（复杂任务用更强模型）
3. 调整温度参数（精确任务用低温度）
4. 补充高质量的知识库内容

### Q5: 工作流运行失败？
1. 检查节点配置是否完整
2. 确认节点之间的数据流是否正确
3. 查看错误日志定位问题节点
4. 确保所有依赖的服务（模型、工具）可用
